02 / CASO REAL DE INTEGRAÇÃO E DATA QUALITY

Uma entrega diária de dados. Vários clientes, destinos e exceções.

A necessidade era disponibilizar arquivos de qualidade de dados no destino correto de cada cliente. A solução precisava funcionar diariamente, mostrar o que falhou e permitir reprocessar uma data quando necessário.

01 / NECESSIDADE

Identificar os arquivos do dia.

Os arquivos Parquet de Data Quality chegavam ao Amazon S3. A rotina precisava localizar diariamente os arquivos referentes a D-1, sem depender de uma busca manual.

02 / INTEGRAÇÃO

Enviar cada arquivo ao cliente correto.

O Azure Data Factory percorria os clientes e consultava no Azure SQL o malote de destino. A movimentação passava pelo Azure Blob antes da entrega no OCI Object Storage.

03 / CONTROLE DE FALHAS

Registrar a exceção sem parar tudo.

Quando faltava o cadastro de um malote, o fluxo registrava a ocorrência e seguia para os demais clientes. Logs, tentativas de nova execução e reprocessamento por data ajudavam a investigar e corrigir falhas.

04 / DISPONIBILIZAÇÃO

Deixar o resultado acessível à operação.

Além da entrega no malote mapeado, uma rotina agendada em Kubernetes copiava arquivos prontos do staging para um diretório compartilhado, usado pelo portal de visualização.
